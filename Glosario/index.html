Glosario de Sistemas Distribuidos y Escalabilidad

Alta disponibilidad (High Availability)

Capacidad de un sistema distribuido para mantenerse operativo y accesible incluso cuando ocurren fallos en alguno de sus componentes, garantizando continuidad en el servicio.

Arquitectura distribuida

Modelo de diseño de sistemas en el que los componentes de procesamiento y almacenamiento se encuentran distribuidos en múltiples nodos o servidores que trabajan de manera coordinada.

Balanceo de carga (Load Balancing)

Técnica utilizada para distribuir las solicitudes o cargas de trabajo entre múltiples servidores o nodos con el fin de optimizar el rendimiento, evitar sobrecargas y mejorar la disponibilidad del sistema.

Cluster

Conjunto de servidores o nodos que trabajan de manera conjunta como una única unidad lógica para proporcionar mayor capacidad de procesamiento, almacenamiento y disponibilidad.

Escalabilidad

Capacidad de un sistema para adaptarse al crecimiento en la cantidad de datos, usuarios o transacciones, manteniendo niveles adecuados de rendimiento.

Escalabilidad horizontal (Scale-out)

Estrategia de crecimiento de sistemas que consiste en añadir más nodos o servidores a la infraestructura para distribuir la carga de trabajo.

Escalabilidad vertical (Scale-up)

Estrategia de crecimiento que consiste en aumentar la capacidad de un único servidor mediante la ampliación de recursos como CPU, memoria o almacenamiento.

Nodo

Unidad individual dentro de un sistema distribuido que participa en el procesamiento o almacenamiento de datos.

Particionamiento de datos (Sharding)

Técnica que consiste en dividir grandes conjuntos de datos en fragmentos más pequeños distribuidos entre diferentes nodos del sistema, permitiendo mejorar la escalabilidad y el rendimiento.

Replicación de datos

Proceso mediante el cual los datos se copian y mantienen sincronizados en múltiples nodos dentro de un sistema distribuido para mejorar la disponibilidad y tolerancia a fallos.

Sistema distribuido

Conjunto de computadoras o nodos independientes que trabajan de manera coordinada para ofrecer servicios o gestionar datos como si se tratara de un único sistema.

Tolerancia a fallos (Fault Tolerance)

Capacidad de un sistema para continuar funcionando correctamente incluso cuando uno o varios componentes fallan.
