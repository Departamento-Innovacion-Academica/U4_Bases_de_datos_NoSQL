1.1.2.6 Sistema de replicación

✕

Permite mantener copias de los datos en diferentes nodos.

Funciones:

  • Alta disponibilidad
  • Recuperación ante fallos
  • Lectura distribuida

Ejemplo:

Nodo principal → Nodo réplica 1 → Nodo réplica 2

1.1.2.7 Gestor de consistencia

✕

Este componente controla cómo se sincronizan los datos entre nodos (Microsoft, 2024a)

Define:

  • Cuando se actualizan las réplicas
  • Qué versión del dato es válida
  • Cómo resolver conflictos

Es clave para mantener coherencia del sistema.

1.1.2.8 Sistema de monitoreo

✕

Supervisa el estado del sistema distribuido.

Permite:

  • Detectar fallos
  • Medir rendimiento
  • Alertar sobre problemas
  • Analizar uso de recursos
