1.3.2.6

Relación con bases NoSQL

Las bases NoSQL facilitan el procesamiento distribuido debido a:

  • Almacenamiento distribuido
  • Flexibilidad de datos
  • Integración con frameworks

Ejemplo:

MongoDB → Spark → análisis distribuido
1.3.2.7

Desafíos del procesamiento distribuido

  • Coordinación entre nodos
  • Latencia de red
  • Gestión de errores
  • Sincronización de datos
  • Complejidad de desarrollo
1.3.2.8

Ejemplo práctico

Análisis de millones de registros de ventas:

Ventas globales → procesamiento en nodos → reporte consolidado

Cada nodo procesa una región específica.

1.3.2.9

Procesamiento en tiempo real

Además del procesamiento Batch, existen sistemas en tiempo real:

  • Streaming de datos
  • Análisis continuo
  • Eventos en línea

Ejemplo:

Eventos de usuarios → procesamiento inmediato → respuesta en segundos
